## What I'm building

**[Kanz e Aza](https://kanz-e-aza.com)**: a free, offline-first catalog of Azadari poetry (nohay, manqabat, marsiya and more) in Roman Urdu and Urdu: an Android app, a website and an open dataset.

- Built to keep running for years on almost no budget. The catalog lives in [Kanz-e-Aza-Lyrics](https://github.com/The-Tech-Boi/Kanz-e-Aza-Lyrics) under CC BY 4.0 and is published by GitHub Actions; the app and website download only what changed.
- Every new lyric or correction is reviewed by a person before it ships, and every lyric has a public history.
- Offline search that matches Roman Urdu spelling variants (Hussain / Husain / Husayn).
